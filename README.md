School Management System (Python)

A beginner-friendly, menu-driven school management application built using core Python concepts.

Features

- Admin login with limited attempts
- Student admission and duplicate roll-number checking
- View and search student records
- Record and view attendance
- Calculate attendance percentage
- Add and update subject marks
- Calculate total marks and percentage
- Record fee payments
- Generate fee balance reports

Technologies Used

- Python 3
- Lists and dictionaries
- Loops and conditional statements
- Functions and built-in operations
- Console-based input and output

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

python school_management.py

On some systems, use "python3 school_management.py".

Data Storage

This version stores records in memory. Student information is lost when the program exits.

Limitations

- The application is a learning project, not production-ready software.
- Authentication uses hardcoded credentials and is not secure.
- Input validation and error handling can be improved.
- Records are not saved between sessions.

Future Improvements
